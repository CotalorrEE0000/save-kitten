# save-kitten

这是一个教学知识库，有大约8个月的学习流程，最后学会能把约束写成机器可判定、可单测、可审计的策略，而非依赖提示词自觉，能在不用 AI 的条件下从原理讲清任一已完成子系统，并指出当初的一个错判，能给资深者提出有实质内容的 review 意见，并把它抽象成下次不再犯的原则，能交付一条从零到可玩 demo 的完整链路，并说明每一处规约由谁检查。
公开凭证：engine-sdk 模板仓库、可玩 demo、Rego 策略与单测、decision log、ADR 集、事故复盘、规约手册、AGENTS.md、反向 review 记录。能反向 review 资深者，从「被评价」走到「参与制定评价标准」，这是协作者与执行者的分界。带 agent 做子系统。
